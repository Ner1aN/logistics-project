# 08. API и интеграции

## Контекст

Текущая версия проекта реализована как Django Templates-приложение. Отдельный REST API в проекте не реализован. Ниже описан возможный API как аналитический артефакт для развития системы.

## Возможные endpoint'ы

| Endpoint | Method | Назначение |
|---|---|---|
| `/api/clients/` | GET | Получить список клиентов |
| `/api/clients/` | POST | Создать клиента |
| `/api/drivers/` | GET | Получить список водителей |
| `/api/vehicles/` | GET | Получить список ТС |
| `/api/requests/` | GET | Получить список заявок |
| `/api/requests/` | POST | Создать заявку |
| `/api/requests/{id}/` | GET | Получить карточку заявки |
| `/api/requests/{id}/` | PATCH | Изменить заявку |
| `/api/requests/{id}/transportations/` | POST | Добавить ТС к заявке |
| `/api/transportations/{id}/` | GET | Получить карточку перевозки |
| `/api/transportations/{id}/` | PATCH | Изменить перевозку |
| `/api/reports/requests/` | GET | Получить отчет по заявкам |
| `/api/reports/export/pdf/` | GET | Скачать PDF-отчет |
| `/api/reports/export/excel/` | GET | Скачать Excel-отчет |

## Примеры контрактов

### Создание заявки

`POST /api/requests/`

Входные данные:

```json
{
  "client_id": 1,
  "cargo_type": "sand",
  "cargo_name": "Песок карьерный",
  "cargo_weight": 12.5,
  "cargo_volume": null,
  "route_from": "Карьер Южный",
  "route_to": "Строительная площадка",
  "transportation_date": "2026-06-20",
  "cost": null,
  "status_id": 1,
  "comment": "Разгрузка до 14:00"
}
```

Выходные данные:

```json
{
  "id": 101,
  "client_id": 1,
  "status": "new",
  "cost": "8875.00",
  "archived": false
}
```

Ошибки:

| Код | Условие |
|---|---|
| 400 | Не указан статус |
| 400 | Не указаны масса и объем |
| 404 | Клиент не найден |

### Добавление ТС к заявке

`POST /api/requests/{id}/transportations/`

Входные данные:

```json
{
  "vehicle_id": 3,
  "driver_id": 4,
  "trip_count": 2,
  "distance_parking_to_loading_km": 5,
  "distance_loading_to_customer_km": 20,
  "distance_customer_to_loading_km": 18,
  "assigned_at": "2026-06-20T09:00:00",
  "notes": "Два рейса в течение дня"
}
```

Выходные данные:

```json
{
  "id": 55,
  "request_id": 101,
  "vehicle_id": 3,
  "driver_id": 4,
  "total_distance_km": "63.00",
  "distance_cost": "6300.00"
}
```

Ошибки:

| Код | Условие |
|---|---|
| 400 | Заявка архивная или завершенная |
| 400 | Водитель занят в другой активной перевозке |
| 400 | ТС занято в другой активной перевозке |
| 400 | Количество рейсов меньше 1 |
| 400 | Километраж отрицательный |

### Изменение статуса заявки

`PATCH /api/requests/{id}/`

Входные данные:

```json
{
  "status_id": 5
}
```

Выходные данные:

```json
{
  "id": 101,
  "status": "completed",
  "archived": true,
  "history_created": true
}
```

Ошибки:

| Код | Условие |
|---|---|
| 404 | Заявка не найдена |
| 400 | Статус не найден |

## Возможные интеграции

| Интеграция | Назначение | Данные |
|---|---|---|
| Карты / геокодер | Автоматический расчет расстояния между адресами | Адрес загрузки, адрес выгрузки, координаты |
| SMS / email | Уведомление клиента или водителя | Телефон, email, статус, дата |
| Бухгалтерская система | Передача стоимости перевозки | Клиент, заявка, стоимость, дата |
| CRM | Получение клиентов и заказов | Контакты, заявки, история |
| Телематика транспорта | Контроль фактического пробега | ТС, GPS, пробег, время |

## Ошибки и валидация

Потенциальный API должен возвращать понятные ошибки:

- обязательное поле не заполнено;
- объект не найден;
- водитель занят;
- ТС занято;
- заявка закрыта для назначения;
- нарушена бизнес-валидация по рейсам или километражу.
