# 12. Summary для резюме

## Краткое описание проекта

Django-проект, разработанный в рамках выпускной квалификационной работы для автоматизации деятельности менеджера компании по грузоперевозкам. Система позволяет вести клиентов, водителей, транспортные средства, заявки, статусы, назначения перевозок, расчет стоимости, архив и отчетность.

## Что сделал как системный аналитик

- Описал предметную область грузоперевозок.
- Выделил ключевых стейкхолдеров: клиент, менеджер, водитель, руководство, система.
- Сформулировал функциональные и нефункциональные требования.
- Описал user stories с acceptance criteria.
- Подготовил use cases по основным сценариям.
- Зафиксировал бизнес-правила.
- Описал модель данных и связи сущностей.
- Подготовил Mermaid ER-диаграмму.
- Описал AS-IS и TO-BE процессы.
- Подготовил возможные API-контракты.
- Составил сценарии тестирования и приемки.
- Подготовил SQL-запросы для аналитических выборок.

## Что реализовано технически

- Django-приложение с авторизацией.
- Справочники клиентов, водителей и ТС.
- Реестр заявок.
- Карточка заявки.
- История изменения статусов.
- Назначение одного или нескольких ТС на заявку.
- Учет количества рейсов.
- Учет трех плеч маршрута.
- Расчет стоимости груза и километража.
- Раздел активных и архивных заявок.
- Отчеты с диаграммами.
- PDF-экспорт отчетов.
- Excel-экспорт отчетов.
- Демоданные.
- Автоматические тесты бизнес-логики.

## Вариант описания проекта для резюме 1

Разработал и описал систему управления грузоперевозками для автоматизации работы менеджера по логистике. Подготовил аналитические артефакты: требования, user stories, use cases, бизнес-правила, модель данных, BPMN-процессы, тестовые сценарии и SQL-запросы. Реализована логика заявок, статусов, истории изменений, назначения транспорта, расчета стоимости, отчетности и экспорта в PDF/Excel.
