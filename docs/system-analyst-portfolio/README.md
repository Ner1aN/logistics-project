# Портфолио системного аналитика: система управления грузоперевозками

## О проекте

Проект представляет собой учебное веб-приложение для автоматизации работы менеджера компании по грузоперевозкам. Система помогает вести клиентов, водителей, транспорт, заявки, назначения перевозок, статусы, отчеты и архив.

Тема диплома: «Программное решение автоматизации деятельности менеджера компании по грузоперевозкам».

## Бизнес-проблема

До внедрения подобной системы менеджер ведет заявки, статусы, назначение водителей и транспорта в разрозненных таблицах или вручную. Из-за этого возникают риски:

- повторное назначение занятого водителя или транспортного средства;
- потеря истории изменения статусов;
- ручной и непрозрачный расчет стоимости;
- сложность контроля активных и архивных заявок;
- отсутствие единого отчета по заявкам, перевозкам и загрузке ресурсов.

## Моя роль в кейсе

В рамках портфолио кейс оформлен с позиции стажера / junior системного аналитика:

- описал предметную область и целевую аудиторию;
- выделил заинтересованные стороны;
- сформулировал функциональные и нефункциональные требования;
- описал user stories и use cases;
- зафиксировал бизнес-правила;
- описал модель данных и связи сущностей;
- подготовил варианты API и интеграций;
- описал AS-IS и TO-BE процесс обработки заявки;
- подготовил сценарии тестирования и приемки;
- составил SQL-примеры для аналитических выборок;
- подготовил текст для резюме.

## Ключевая бизнес-логика

- Статус заявки является обязательным полем при создании.
- Статус выбирает менеджер, система не назначает статус автоматически по умолчанию.
- Если стоимость не указана вручную, система рассчитывает ее автоматически.
- Если стоимость указана вручную, система не перезаписывает ее.
- Для заявки должна быть указана масса или объем груза.
- Для типа груза используются разные тарифы: песок, щебень, бетон.
- Перевозка может включать несколько транспортных средств.
- Для каждого ТС указываются количество рейсов и три плеча маршрута.
- Стоимость перевозки включает стоимость груза и стоимость километража.
- Изменение статуса фиксируется в истории.
- Завершенные и отмененные заявки архивируются.
