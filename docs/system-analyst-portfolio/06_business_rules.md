# 06. Бизнес-правила

| ID | Правило |
|---|---|
| BR-01 | При создании заявки статус является обязательным полем. |
| BR-02 | Статус заявки выбирает менеджер. |
| BR-03 | Система не назначает статус заявки автоматически по умолчанию вместо менеджера. |
| BR-04 | В заявке должна быть указана хотя бы масса или объем груза. |
| BR-05 | Если указаны и масса, и объем, при расчете стоимости приоритет имеет масса. |
| BR-06 | Если стоимость не указана вручную, система рассчитывает ее автоматически. |
| BR-07 | Если стоимость указана вручную, система не перезаписывает ее автоматическим расчетом. |
| BR-08 | Автоматический расчет стоимости зависит от типа груза: песок, щебень, бетон. |
| BR-09 | Базовая ставка расчета стоимости груза равна 2000 ₽. |
| BR-10 | Тарифы по песку: 550 ₽/т и 350 ₽/м3. |
| BR-11 | Тарифы по щебню: 650 ₽/т и 420 ₽/м3. |
| BR-12 | Тарифы по бетону: 1200 ₽/т и 900 ₽/м3. |
| BR-13 | Стоимость километража рассчитывается по фиксированному тарифу 100 ₽/км. |
| BR-14 | Для каждого назначения ТС фиксируются три плеча маршрута. |
| BR-15 | Общий километраж ТС считается по формуле: плечо 1 + плечо 2 * количество рейсов + плечо 3 * (количество рейсов - 1). |
| BR-16 | На одну заявку может быть назначено несколько ТС. |
| BR-17 | Суммарная грузоподъемность заявки считается как сумма грузоподъемности назначенных ТС с учетом количества рейсов. |
| BR-18 | Занятый водитель не может быть назначен на другую активную перевозку. |
| BR-19 | Занятое ТС не может быть назначено на другую активную перевозку. |
| BR-20 | Изменение статуса заявки фиксируется в истории статусов. |
| BR-21 | Статусы completed и cancelled переводят заявку в архив. |
| BR-22 | Архивные и завершенные заявки нельзя использовать для нового назначения перевозки. |
| BR-23 | При назначении перевозки заявка может перейти в статус assigned, если ранее была новой или в обработке. |
| BR-24 | При завершении или отмене заявки занятость водителя и ТС пересчитывается. |
| BR-25 | Демоданные должны создаваться повторяемо без дублирования заявок при повторном запуске команды. |

## Формулы расчета

Стоимость груза по массе:

```text
стоимость_груза = 2000 + масса_тонн * тариф_за_тонну
```

Стоимость груза по объему:

```text
стоимость_груза = 2000 + объем_м3 * тариф_за_м3
```

Километраж одного ТС:

```text
километраж_ТС = плечо_1 + плечо_2 * рейсы + плечо_3 * (рейсы - 1)
```

Стоимость километража:

```text
стоимость_километража = сумма_километража_всех_ТС * 100
```

Итоговая стоимость:

```text
итоговая_стоимость = стоимость_груза + стоимость_километража
```
