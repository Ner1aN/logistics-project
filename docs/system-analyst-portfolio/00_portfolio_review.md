# 00. Финальная ревизия портфолио

## Что входит в портфолио

Портфолио оформлено как аналитический кейс на основе работающего Django-проекта по автоматизации деятельности менеджера компании по грузоперевозкам. В кейсе показано, как бизнес-логика системы описана через требования, сценарии, правила, модель данных, процессы, тестирование и SQL-выборки.

Документация дополняет код проекта и не заменяет его: реализованная часть находится в Django-приложении `logistics`, а раздел API описан как возможное направление развития, потому что отдельный REST API в текущей версии не реализован.

## Подготовленные артефакты

- описание цели системы, проблемы и границ проекта;
- карта стейкхолдеров;
- функциональные и нефункциональные требования;
- user stories с acceptance criteria;
- use cases по ключевым сценариям;
- бизнес-правила и формулы расчета;
- описание модели данных и Mermaid ER-диаграмма;
- аналитическое описание возможного API и интеграций;
- AS-IS / TO-BE процесс и Mermaid flowchart;
- сценарии тестирования и приемки;
- SQL-примеры для аналитических выборок;
- summary и формулировки для резюме.

## Какие навыки системного аналитика демонстрирует проект

- анализ предметной области и выделение участников процесса;
- формализация требований и ограничений;
- описание пользовательских сценариев и use cases;
- фиксация бизнес-правил и расчетных формул;
- работа с моделью данных и связями сущностей;
- проектирование возможных API-контрактов;
- описание процесса в формате AS-IS / TO-BE;
- подготовка приемочных проверок;
- составление SQL-запросов для отчетности и анализа данных;
- проверка документации на соответствие реализованной системе.

## Что можно показывать работодателю

- главный README портфолио как навигацию по кейсу;
- требования, user stories и use cases как пример работы с функциональностью;
- бизнес-правила и формулы расчета стоимости как пример формализации логики;
- ER-диаграмму и описание сущностей как пример анализа данных;
- AS-IS / TO-BE процесс как пример процессного описания;
- тестовые сценарии и SQL-примеры как подтверждение прикладного аналитического подхода;
- summary для резюме как краткое описание проекта и личного вклада.
